Квадратное уравнение (-q)

Один корень:
.\task03.exe -q 0.000001 1 -2 1
Для уравнения x^2 - 2x + 1 ожидается корень x = 1.

Два корня:
.\task03.exe -q 0.000001 1 -3 2
Для уравнения x^2 - 3x + 2 ожидаются корни x = 1 и x = 2.

Корней нет:
.\task03.exe -q 0.000001 1 0 1
Для уравнения x^2 + 1 ожидается: корней нет.

Проверка кратности (-m)

Делится:
.\task03.exe -m 12 3
Ожидается: 12 кратно 3.

Не делится:
.\task03.exe -m 12 5
Ожидается: 12 не кратно 5.

Прямоугольный треугольник (-t)

Прямоугольный:
.\task03.exe -t 0.000001 3 4 5
Ожидается: прямоугольный.

Не прямоугольный:
.\task03.exe -t 0.000001 2 3 4
Ожидается: не прямоугольный.

Неизвестный флаг:
.\task03.exe -x
Ожидается: task03 -q <eps> a b c | -m n1 n2 | -t <eps> a b c

Мало чисел для уравнения:
.\task03.exe -q 0.000001 1 2
Ожидается: Для -q: эпсилон и 3 коэффициента

Мало чисел для кратности:
.\task03.exe -m 12
Ожидается: Для -m: два целых

Ноль во втором числе:
.\task03.exe -m 12 0
Ожидается: Некорректные данные

Сторона не длиннее точности:
.\task03.exe -t 0.001 0 3 5
Ожидается: Некорректные данные

Эпсилон больше 1:
.\task03.exe -q 1.5 1 -2 1
Ожидается: Некорректные данные
