
Удалить цифры:
.\task04.exe -d sample.txt
В out_sample.txt ожидается:
Abc !
Hi, .

Посчитать латинские буквы в каждой строке:
.\task04.exe -i sample.txt
В out_sample.txt ожидается:
3
2

Посчитать знаки, которые не буквы, не цифры и не пробелы:
.\task04.exe -s sample.txt
В out_sample.txt ожидается:
1
2

Заменить символы их шестнадцатеричными кодами:
.\task04.exe -a sample.txt

Указать имя выходного файла самостоятельно:
.\task04.exe -nd sample.txt result.txt
Результат появится в result.txt.

Проверка ошибки (такого файла нет):
.\task04.exe -d nofile.txt
Ожидается: Не открылся входной файл

Неизвестный флаг:
.\task04.exe -x sample.txt
Ожидается: task04 <-d|-i|-s|-a> файл | <-nd|-ni|-ns|-na> вход выход

Плохое имя, путь кончается разделителем:
.\task04.exe -d sample.txt\
Ожидается: Плохое имя файла

Выходной файл в несуществующей папке:
.\task04.exe -nd sample.txt missing_folder\result.txt
Ожидается: Не открылся выходной файл

Вход и выход — один и тот же файл:
.\task04.exe -nd sample.txt sample.txt
Ожидается: Вход и выход совпадают
